# Entertainment Store - Frontend

Frontend for a simple movie streaming platform built with React and TypeScript.
Website link : https://entertainmentstore-frontend.nowrise5.workers.dev/ 

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Better Auth
- REST API

## Features

- User authentication
- Movie browsing
- Movie details
- Video streaming
- User profile
- Watch history
- Responsive UI
- Backend API integration
